# React

    Camada de interface

* É uma biblioteca JavaScript para interface de usuário
* Formada por componentes: pequenas unidades independentes e reutilizáveis
* Quando o estado muda, o react atualiza a interface
* Usado em dashboards, telas dinâmicas, sistemas administrativos e produtos digitais

## Componente

    Função do JavaScript que retorna os elementos que serão exibidos na interface

* Menus, cabeçalho, botão, produto, formulário, rodapé...

Um componente pode usar outrso componentes

O nome do componentes começa com letra maiúscula

## Instalação

1. node --version
2. npm --version

## Criando um projeto

1. Abrir uma pasta de trabalho no vs code
2. Abrir no terminal
3. Executar o comando de criação do projeto
4. Escolher o react como framework


```
npm create vite@latest [nome do projeto] -- --
template react
cd meu-projeto
npm install
npm run dev
```
